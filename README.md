# AI Product Discovery Platform

A Claude Code–driven platform of modular skills and agents for product
discovery — market research, customer insight synthesis, competitive
analysis, opportunity framing, and early-stage artifact generation.

This repository is currently **scaffolding only** — structure and
conventions, no discovery skills implemented yet.

Start here:

- [`CLAUDE.md`](./CLAUDE.md) — project philosophy and operating principles
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — how future skills and agents must be designed
- [`.claude/`](./.claude) — skills, agents, templates, memory, outputs, and examples, each with its own README
